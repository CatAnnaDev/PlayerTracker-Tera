# PlayerTracker

Every command starts with `!notes`.

| Command | Description |
|---|---|
| `list [page]` | List all recorded players, most recent first |
| `find <text>` | Search by name, alias, main, note or guild |
| `info <name>` | Show a player's details |
| `rename <name> <alias>` | Set an alias (empty to remove) |
| `note <name> <text>` | Set a note (empty to remove) |
| `alt <name> <main>` | Mark a player as a reroll of a main (empty to remove) |
| `alts <main>` | List all known rerolls of a main |
| `suggest [name]` | Show probable alt pairs, global or for one player |
| `group <name>` | Show players sharing the same account signature |
| `head on\|off` | Show notes above heads |
| `chat on\|off` | Show notes in chat and whispers |
| `forget <name>` | Remove a player and their links |
| `stats` | Show tracking statistics |
